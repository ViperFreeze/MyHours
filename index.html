Sauvegarde automatique

Après chaque modification, une copie de toutes vos données part dans un Gist privé de votre compte GitHub, qui garde l'historique des versions. Sur un nouveau téléphone, collez le même jeton : la sauvegarde est retrouvée et fusionnée.

Pas encore de jeton ? Créez-le sur GitHub : la case gist est déjà cochée, choisissez « No expiration », puis copiez le jeton ici. Il reste sur cet appareil et n'est jamais exporté.

Sauvegarde Google Drive

Une copie de toutes vos données est gardée dans un dossier caché de votre Google Drive. « Restaurer » remplace les données de cet appareil par cette copie (nouveau téléphone, réinstallation…).

Fichier de sauvegarde

Sans compte Google : « Exporter » crée un fichier à vous envoyer (Drive, mail, messagerie…). « Importer » le fusionne sur un autre appareil : rien n'est écrasé, les suppressions sont reportées.
